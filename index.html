Software Engineering & Design

The first enhancement was my Software Design and Engineering enhancement. This enhancement involved separating the logic and UI of my Activity class, which originally performed most of the key functionality of my inventory app, including inventory management. Before this enhancement, much of the functionality was performed within one class. From a simplicity standpoint, this made sense when I originally designed it that way because it allowed me to keep most of the heavy lifting in one place without having to move back and forth between classes. However, this approach is not ideal in the long run because if another developer, or even myself, wanted to add enhancements or fix bugs, the code could quickly become cluttered and difficult to manage. This could lead to a number of problems that would slow down future development and make bug fixing more difficult.

Data Structures and Algorithms

I have utilized some knowledge of Data Structures & Algorithms, specifically by using a HashMap to negate duplicate data. Originally, I planned to use the HashMap to search for items in my inventory, but I realized that using a linear search for my app was more efficient and reworked my HashMap idea to help filter out duplicate data.
